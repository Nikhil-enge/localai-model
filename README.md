# localai-model

A simple AI study assistant that summarizes study notes using the QVAC SDK.

## Features

- Summarizes study notes
- Runs AI inference locally on-device
- React frontend
- Node.js and Express backend
- Simple and responsive interface

## Technologies Used

- React
- Vite
- Node.js
- Express
- QVAC SDK
